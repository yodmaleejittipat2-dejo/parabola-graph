# Parabola Graph

เว็บแอปวาดกราฟพาราโบลาจากสมการกำลังสอง พร้อมบอกจุดยอด จุดสูงสุด/ต่ำสุด และค่าสูงสุด/ต่ำสุด ตามหลักคณิตศาสตร์ ติดตั้งเป็นแอปบนมือถือหรือคอมพิวเตอร์ได้ และใช้งานแบบออฟไลน์ได้

**สร้างโดย Jittipat**

## ความสามารถ

- พิมพ์สมการได้หลายรูปแบบ เช่น `y = 2x²`, `y = x^2 - 4x + 3`, `y = -(x - 1)^2 + 4`, `y = (x + 2)(x - 3)`
- บอกจุดยอด จุดต่ำสุด/สูงสุด ค่าต่ำสุด/สูงสุด แกนสมมาตร จุดตัดแกน x และ y ดิสคริมิแนนต์ โดเมน และเรนจ์
- แสดงวิธีทำทีละขั้น ตั้งแต่หา h = −b/2a และ k = c − b²/4a จนได้รูปจุดยอด
- ตารางค่า x, y เลือกได้ 5, 7 หรือ 9 จุด โดยให้จุดยอดอยู่ตรงกลาง พร้อมแสดงการแทนค่า
- กดดูทีละจุด (A, B, C, …) ได้ทั้งจากกราฟ ตาราง หรือปุ่ม ◀ ▶
- ตั้งช่วงแกน x และแกน y เองได้ หรือให้ระบบตั้งอัตโนมัติ
- ลากเลื่อน ซูม และแตะเพื่ออ่านค่าบนกราฟ
- รองรับโหมดสว่างและโหมดมืด
- ไม่ใช้ไลบรารีภายนอก วาดกราฟด้วย Canvas และวาดใหม่เฉพาะเมื่อมีการเปลี่ยนแปลง จึงเบาเครื่อง

## นำขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `parabola-graph` (ตั้งเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ราก (root) ของ repository
   (กด **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ `icons` ทั้งหมดลงไป จากนั้นกด **Commit changes**)
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก **Deploy from a branch** เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/parabola-graph/`

## ติดตั้งเป็นแอป

- **Chrome / Edge บนคอมพิวเตอร์และ Android:** กดปุ่ม **ติดตั้งแอป** มุมขวาบนของหน้าเว็บ หรือกดไอคอนติดตั้งในแถบที่อยู่
- **Safari บน iPhone / iPad:** กดปุ่มแชร์ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**

หลังเปิดใช้งานครั้งแรก แอปจะใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## อัปเดตแอป

เมื่อแก้ไขไฟล์แล้ว ให้เปลี่ยนเลขเวอร์ชันในไฟล์ `sw.js` ด้วย (เช่น `parabola-graph-v1` เป็น `parabola-graph-v2`) เพื่อให้เครื่องที่ติดตั้งแอปไว้ได้รับไฟล์ใหม่

## โครงสร้างไฟล์

```
index.html             หน้าแอปทั้งหมด (HTML, CSS, JavaScript)
manifest.webmanifest   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                  service worker สำหรับใช้งานออฟไลน์
icons/                 ไอคอนแอป
.nojekyll              ให้ GitHub Pages ส่งไฟล์ตามที่เป็น
```
